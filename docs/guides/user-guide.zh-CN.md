# Live2Pet 使用指南

[返回 README](../../README.zh-CN.md) · [English](user-guide.md)

## 首次启动

1. 按 README 中的命令构建 macOS App。
2. 如果未签名 App 被拦截，在“系统设置 → 隐私与安全性”中允许打开。
3. 在首次引导中添加运行时，也可以稍后在预览模型时配置。

<a id="compatibility"></a>

## 兼容性

| 资源 | 文件与限制 |
| --- | --- |
| Cubism 3–5 | `.model3.json`、`.moc3` 及引用的纹理和动作 |
| Cubism 2 | `.model.json`、`.moc` 及引用的纹理和动作 |
| Live2D PCK | 受支持的未压缩、未加密结构；PCK 是容器，不专属于某个游戏 |
| Spine 4.0–4.3 | JSON 或二进制骨骼、匹配的图集和纹理；支持默认皮肤及 Slot 隐藏 |
| Codex 输出 | V2 11 行图集，九个动画映射与中立方向格，暂不生成方向跟随 |
| Clawd 输出 | 透明 WebP 动画、必选及可选状态、互动反应 |

Spine 4.1 二进制和 4.3 JSON 已有本地集成测试覆盖；4.0/4.2 和打包 App 完整流程仍待真实模型验收。Windows 计划在 V1 之后支持。

<a id="runtimes"></a>

## 运行时配置

模型包含角色数据，运行时负责让它动起来。Live2D 专有运行时需要单独取得，不随 Live2Pet 分发。

| 模型 | 获取方式 |
| --- | --- |
| Cubism 3–5 | [官方 Web SDK](https://www.live2d.com/en/sdk/download/web/) → `Core/live2dcubismcore.min.js` |
| Cubism 2 | [第三方存档](https://github.com/dylanNew/live2d/tree/master/webgl/Live2D/lib) → `live2d.min.js` |
| Spine 4.0–4.3 | 在 App 内安装匹配的可选渲染器 |

- 下载 **Web SDK**，不要选择 Editor、Unity 或 Native SDK。
- Cubism 2 需要 JavaScript 文件，而不是 GitHub 网页。该存档由第三方提供；[Live2D 已停止提供新的 Cubism 2.1 SDK 下载](https://help.live2d.com/en/other/other_20/)。
- 将文件或解压后的 SDK 文件夹拖入“设置 → 运行时”。
- App 保存本地副本并自动匹配版本；移除副本不会删除原始文件。
- Spine 仅在点击“安装”后下载，使用受 [Spine Runtime License](https://github.com/EsotericSoftware/spine-runtimes/blob/4.3/LICENSE) 约束。
- 检查资源不需要运行时，播放与捕获需要。

## 浏览与选择模型

- **本地：** 在“模型”页面任意位置拖入或浏览文件夹，最多扫描其下两层模型目录；模型卡进入可见区域后才按需生成缩略图。
- **GitHub：** 粘贴公开仓库或文件夹链接。浏览时只读取目录信息，选中卡片后才下载该模型。“下载全部”会获取检测到的全部模型，显示确定进度，单个失败不会中断其余下载，完成后汇总新下载、已缓存和失败数量；缩略图仍按可见区域懒加载。
- **PCK：** 直接导入或拖入受支持的文件。
- 在预览里检查版本、资源、警告与动作，然后点击“使用并开始映射”。

确认前的浏览不会替换当前项目；从映射页返回后模型库仍可继续使用。

## 映射与调整

“动画 / 模型预览 / 目标配置”三栏宽度可以拖动调整，也支持键盘方向键。

| 控件 | 用途 |
| --- | --- |
| 动作 | 选择动画；模型提供表情时才显示表情选项 |
| 播放控制 | 播放、暂停、重放、拖动进度、循环及预览倍速 |
| 显示与隐藏 | 查看部件小图与父子层级 |
| 单独查看 | 临时检查一个元素 |
| 隐藏 / 显示 | 同时应用到预览和生成包 |
| 检测大范围元素 | 在现代 Cubism 动作中寻找宽大元素 |
| 重置预览 | 重新创建模型预览 |

Clawd 与 Codex 分别配置。必选状态需要填满，可选状态可以留空。Clawd 的拖拽或双击反应未映射时，生成主题会复用待机动作以保持可互动；用户显式映射的反应始终优先。同一个网格中的人物与背景无法在这里拆分。

## 构建、保存与安装

1. 在“构建”中给宠物起名字。
2. Clawd 可选“精简 / 平衡 / 高质量”，或自定义分辨率、帧率和 WebP 质量。
3. 构建并检查生成预览。
4. 选择“保存 ZIP”“安装”或“构建并安装”。

“设置 → 存储”可指定输出目录或每次询问保存位置。“设置 → 目标”可检测宿主，也可手动选择 App 与宠物包目录。

Clawd 的 **80 MiB** 限制会显示警告：仍能保存超限 ZIP，但 Clawd 可能拒绝导入。降低质量、分辨率或帧率可减小体积。Codex 使用少量固定帧的短循环，完整长动作适合导出到 Clawd。

安装会请求确认；替换已安装包需要明确确认，并在失败时从备份恢复。

## 应用更新

Live2Pet 会在启动后稍作延迟，通过公开的 GitHub Releases 页面检查正式版，同一设备每 24 小时最多自动检查一次。你可以在“设置 → 通用”中关闭自动检查、立即检查，或在发现新版后打开对应 Release。App 只显示提示，不会自动下载或安装更新。

## 项目与存储

- `.live2pet` 保存映射、渲染选项、隐藏配置和资源引用。
- **不嵌入模型或运行时。** 重新打开或分享项目时，需要保留源文件。
- 未保存编辑会留在本机，供下次启动恢复。
- 清空最近项目不会删除项目文件。
- GitHub 缓存默认 **1 GiB**，可在“设置 → 存储”调整为 **256 MiB–20 GiB**。
- “下载全部”会先检查检测到的模型是否能全部放入当前缓存上限；空间不足时请提高上限或选择范围更小的 GitHub 文件夹。
- 缓存满后淘汰旧条目；正在使用的资源受保护，必要时重启释放。
- GitHub 缓存资源被清理后，需要重新选中模型并关联项目。
- 构建缓存复用捕获帧和编码结果；单条过大时跳过缓存，不影响构建。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 可以检查但无法预览 | 添加匹配运行时；现代 Core 与 Cubism 2 运行时不能互换 |
| PCK 被拒绝 | 检查资源是否完整、受支持、未压缩且未加密 |
| 宠物太小或被裁切 | 检查宽大的动态部件，隐藏可分离杂物，并使用当前 App 重建 |
| Clawd 宠物无法点击 | 使用当前 Live2Pet 重新构建并安装；新主题会生成点击框，并为拖拽和双击生成待机后备。Clawd 的点击反应需要双击，不是单击。 |
| ZIP 太大 | 选择精简档位或降低自定义参数 |
| 没找到宿主 App | “设置 → 目标 → 手动选择应用”，或选择宠物包目录 |
