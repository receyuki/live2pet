# Package Build CLI input

The `live2pet package-build` operation is the CLI's headless build entrypoint. It consumes a transient JSON build spec and calls the shared `buildProjectTargets` service. The spec is not a replacement for an `.l2p` Project and should not be committed with source assets.

## Shape

```json
{
  "schemaVersion": 1,
  "project": { "schemaVersion": 1, "projectId": "...", "source": {}, "targets": {} },
  "targets": ["clawd"],
  "inputsByTarget": {
    "clawd": {
      "framesByMotion": {
        "motion-id": {
          "frames": [{ "width": 2, "height": 2, "rgbaBase64": "..." }]
        }
      }
    }
  },
  "metadataByTarget": {},
  "optionsByTarget": {},
  "runtimeVersion": "...",
  "rendererVersion": "...",
  "encoderVersion": "..."
}
```

`project` is an inline, reference-only Live2Pet Project. `inputsByTarget` must contain pre-captured frames: Clawd uses `framesByMotion`, while Codex uses `candidatesByRow`. Each RGBA capture is supplied as standard base64 under `rgbaBase64`; the CLI converts it to a transient byte buffer and never includes it in JSON output. A build that does not provide captures fails with a typed renderer/input error rather than attempting to locate or execute a runtime.

`targets` is optional; when omitted, the CLI builds every key in `inputsByTarget`. `optionsByTarget` accepts only current build controls (`render`, `renderPreset`, `quality`, `alphaQuality`, `lossless`, `selection`, and `maxBytes`). Runtime, renderer, and encoder versions are optional, but all three are required together with a cache directory before candidate or encoded-asset cache reuse is enabled.

Use `--output <directory>` to export validated packages. Filenames are generated by the shared service as `<package-id>-<target>-<semver>.zip`; existing files are rejected unless `--overwrite` is explicit. Installation is a separate `install` operation and is never implied by `package-build` or export.

The CLI response contains versioned progress events, target previews, reports, validation, cache statistics, and artifact sizes. RGBA buffers, ZIP bytes, bearer tokens, and absolute paths are removed or redacted before the response is emitted.
