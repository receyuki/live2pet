# Use Live2Pet as the product umbrella

The project was originally named Live2Clawd while Clawd themes were its only output. It is renamed Live2Pet because Clawd Theme and Codex Pet are now separate Target Profiles of one broader Live2D-to-agent-pet toolchain. The product, App, CLI, Codex skill, npm scope, and future repository use `Live2Pet` or `live2pet`; `Clawd` and `Codex Pet` remain target-specific names, and the former Live2Clawd name remains only in migration history.
